# 🌱 AgroMart

AgroMart is a Java Full-Stack e-commerce web application designed to connect farmers, sellers, and customers through a simple and user-friendly digital marketplace.

## 🚀 Features

- User registration and login
- Browse agricultural products
- Search and view product details
- Shopping cart
- Wishlist
- Order management
- Seller and product management
- REST API integration
- MySQL database integration
- Responsive web interface

## 🛠️ Technologies Used

### Frontend
- React.js
- HTML
- CSS
- JavaScript
- Vite

### Backend
- Java
- Spring Boot
- REST API
- Maven

### Database
- MySQL
